# 紫垣・紫微斗數排盤

輸入出生資料，排出紫微斗數命盤，並附上星曜與宮位的名詞說明。純靜態網頁，生日資料只保存在使用者自己的瀏覽器，不會上傳。

GitHub Pages 使用 main 分支的 `/docs` 目錄。

## 檔案
- `docs/calendar.js`：1900–2100 年農曆資料，由 `tools/gen_lunar.py` 依天文計算產生（需 `pip install ephem`），請勿手動修改。
- `docs/engine.js`：國曆轉農曆與安星規則，可在 Node 中執行。
- `docs/texts.js`：星曜、四化、宮位與名詞說明。
- `docs/app.js`、`docs/index.html`、`docs/style.css`：畫面。
- `tests/verify.js`：測試，執行 `node tests/verify.js`。

## 排盤規則
依常見通行排法，以《紫微斗數全書》為主：
- 年干支以農曆正月初一換年。
- 命宮、身宮：寅宮起正月順數到生月，再依生時逆數為命宮、順數為身宮。
- 五行局：五虎遁定宮干，依命宮干支納音定局。
- 安星：十四主星、左輔右弼、文昌文曲、天魁天鉞、祿存、擎羊陀羅、火星鈴星、地空地劫、天馬（依生月）、紅鸞天喜、天刑天姚。
- 四化依年干。庚年採「太陽、武曲、太陰、天同」。
- 大限：命宮從局數起，陽男陰女順行、陰男陽女逆行，年齡為虛歲。
- 可調整的設定：
  - 晚子時（23:00 以後）預設算作隔天，可改為算作當天。
  - 閏月預設十五日以前算本月、十六日起算下月，也可改為全算本月或全算下月。
- 在台灣出生時，依瀏覽器內建的時區資料（Asia/Taipei），自動把當年的夏令時間和日治時期時間換算回 UTC+8 標準時間。

## 農曆資料
每月初一為朔日所在的日期，含冬至的月為十一月，有十三個月的年份以第一個沒有中氣的月為閏月。

1929 年起以 UTC+8 計算，之前以北京地方平時計算。1906 與 1922 兩年採 UTC+8，以符合當年實際刊行的曆書（例如 1922 年閏五月）。

測試會與另一份通行農曆表逐月比對，只有三天不同：1933/7/22、1954/11/25、1978/9/2。這三天的朔日落在午夜前後，本站以天文計算為準，詳見 `tests/verify.js`。
